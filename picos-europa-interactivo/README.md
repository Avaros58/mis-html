# Atlas interactivo de los Picos de Europa · v1.0

Primera maqueta funcional para GitHub Pages.

## Incluye
- Zoom con rueda, botones y gestos táctiles.
- Arrastre del panorama.
- Etiquetas HTML nítidas.
- Buscador.
- Filtros por tipos.
- Fichas laterales.
- Diseño responsive.

## Importante
La imagen base y la posición de las etiquetas son provisionales. El objetivo de esta versión es validar el motor interactivo antes de incorporar cartografía definitiva y datos geográficos completos.

## Publicación
Sube la carpeta completa a tu repositorio. El archivo `index.html` debe permanecer en la raíz de esta carpeta.
