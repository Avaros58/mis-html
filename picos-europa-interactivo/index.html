Cómo usar este visor

Este HTML evita el problema de WhatsApp: en vez de enviar la imagen comprimida, comparte el enlace publicado en GitHub Pages. Quien lo abra podrá hacer zoom y moverse por el panorama sin que WhatsApp destruya los textos.

Los puntos interactivos son una primera capa orientativa. Se pueden ampliar con todos los nombres del póster original si vamos incorporando una lista completa de topónimos.

Para publicarlo

Sube esta carpeta completa a GitHub Pages manteniendo la estructura: index.html, assets/img, assets/css y assets/js.
