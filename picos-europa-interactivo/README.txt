Picos de Europa - visor interactivo

Estructura:
- index.html
- assets/img/picos-panorama.png
- assets/img/picos-interface-preview.png
- assets/css/styles.css
- assets/js/app.js

Uso en GitHub Pages:
1. Copia la carpeta completa dentro de tu repositorio.
2. Mantén el nombre index.html.
3. Publica la carpeta desde GitHub Pages.
4. Comparte el enlace público por WhatsApp en lugar de enviar la imagen como foto.

Nota:
Los puntos interactivos son una primera capa. Se pueden ampliar con más cumbres, collados, ríos y refugios.
