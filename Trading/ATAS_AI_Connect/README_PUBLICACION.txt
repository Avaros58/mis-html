ATAS AI CONNECT — PUBLICACIÓN WEB INTERACTIVA
================================================
Contenido del paquete:
- index.html: manual completo, pestañas, selector 100–200 %, biblioteca de 24 prompts y 7 cuestionarios autocorregibles.
- assets/: ilustraciones del manual y portada-redes.jpg (1200×630).
- videos/: los cinco tutoriales originales MP4 (H.264/AAC).
- subtitulos/: cinco pistas españolas y cinco inglesas, en formato WebVTT.

PARA PUBLICAR EN GITHUB PAGES
1. Descomprime el ZIP.
2. Coloca index.html y las carpetas assets/, videos/ y subtitulos/ JUNTOS en la carpeta del repositorio destinada a esta publicación.
3. Sube/commit todos los archivos, no solo index.html. Espera el despliegue de GitHub Pages.
4. Prueba imágenes, vídeos, selector de idiomas CC, cuestionarios y tamaño de letra desde la URL publicada.

PRUEBA LOCAL
- Puedes abrir index.html directamente para consultar los textos e imágenes.
- Para probar correctamente pistas VTT en Chrome/Edge desde disco local, utiliza un servidor HTTP local, por ejemplo:
  python -m http.server 8000
  y abre http://localhost:8000/
  Algunos navegadores limitan pistas VTT abiertas con file:// por política de origen.
