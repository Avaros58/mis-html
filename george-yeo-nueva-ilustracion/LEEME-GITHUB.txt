GEORGE YEO · NUEVA ILUSTRACIÓN
================================

Carpeta preparada para GitHub Pages.

PUBLICACIÓN
1. Sustituya en su repositorio la carpeta anterior
   george-yeo-nueva-ilustracion por esta carpeta completa.
2. Confirme que index.html queda directamente dentro de la carpeta,
   junto a favicon.svg y las subcarpetas images y recursos.
3. Realice el commit y el push a la rama main.
4. La dirección pública conservará la forma:
   https://SU-USUARIO.github.io/SU-REPOSITORIO/george-yeo-nueva-ilustracion/

ESTRUCTURA NECESARIA
- index.html
- favicon.svg
- images/hero.png
- images/bird.png
- recursos/Informe_George_Yeo_Nueva_Ilustracion.pdf
- recursos/Informe_George_Yeo_Nueva_Ilustracion.docx

No se necesitan Node, npm, carpetas de compilación ni archivos JavaScript
externos. Los estilos y la interacción de pestañas están integrados en
index.html; las imágenes y documentos permanecen separados para que las
rutas relativas funcionen en local y en GitHub Pages.

Si el navegador muestra durante unos minutos la versión antigua después
del push, recargue la página con Ctrl+F5.
