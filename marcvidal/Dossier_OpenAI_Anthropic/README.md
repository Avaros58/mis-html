# Dossier · Marc Vidal

Sitio estático listo para GitHub Pages. No necesita instalación ni compilación.

## Publicación

1. Sube los cuatro archivos de esta carpeta a la raíz de un repositorio de GitHub. Mantén sus nombres y sitúalos juntos.
2. En el repositorio, abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, la rama que contiene los archivos (habitualmente `main`) y la carpeta **/ (root)**. Guarda.
4. Abre la dirección que GitHub muestra al finalizar el despliegue.

También funciona dentro de una subcarpeta publicada: los enlaces a los documentos son relativos.

## Archivos

- `index.html`: dossier completo; estilos, interacciones, fuentes tipográficas e ilustraciones SVG integrados.
- `Informe_Analitico_OpenAI_Anthropic.pdf`: informe final de 13 páginas.
- `Informe_Analitico_OpenAI_Anthropic.docx`: documento maestro editable.
- `README.md`: estas instrucciones.

## Uso

Abre `index.html` para consultarlo localmente. Incluye ocho pestañas, lectura continua, ampliación de desplegables e impresión de todos los capítulos. Sin JavaScript, los capítulos permanecen visibles y los desplegables nativos siguen funcionando. El contenido, las ilustraciones, las fuentes y los documentos están disponibles sin conexión; para ver el vídeo se necesita internet.

Las preguntas y respuestas son una síntesis de la conferencia, no un turno de preguntas del vídeo. Las referencias mencionadas por Marc Vidal enlazan al pasaje en que las expone. Las cifras y las interpretaciones se atribuyen al ponente.
