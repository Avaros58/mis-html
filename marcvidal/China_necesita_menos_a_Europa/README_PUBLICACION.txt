F-008 - HTML para publicación en GitHub Pages

Estado: preparado para publicación, pendiente de URL pública definitiva
Fecha: 05-10-2026

Contenido:
- index.html: artículo completo.
- styles.css: presentación responsive y estilos de impresión.
- social-card.png: imagen editorial de cabecera y tarjeta social.
- publication.css: estilos de los accesos de publicación.
- F-008-estudio-editorial-revisado.docx: documento editorial aprobado para descarga.
- .nojekyll: evita que GitHub Pages procese innecesariamente el paquete con Jekyll.

Publicación:
1. Copiar el contenido completo de esta carpeta a la ubicación elegida del repositorio de GitHub Pages.
2. Mantener todos los archivos juntos para conservar las rutas relativas y la descarga del DOCX.
3. Sustituir el canonical relativo (./) y, si se desea, og:url por la URL pública definitiva tras publicar.
4. Comprobar la vista previa de la tarjeta social en la plataforma de destino.
5. Verificar tras el despliegue los dos accesos principales: vídeo de YouTube y descarga del estudio editorial.

No utiliza JavaScript, rastreadores, cookies ni dependencias externas. El enlace a YouTube es la única salida externa del artículo. El DOCX se sirve desde el mismo directorio de GitHub Pages.
