# Lorenzo Ramírez y las estructuras de poder

Entrega independiente de los proyectos existentes. Paquete estático para GitHub Pages. No publicado.

## Lectura y publicación

Abrir index.html localmente. Para publicar, subir su contenido junto con assets y documentos a una carpeta independiente del repositorio. Conservar las rutas y activar o utilizar la configuración existente de GitHub Pages. No hace falta compilación ni instalación.

El ZIP de publicación incluye solo index.html, .nojekyll, README.md, assets y documentos. No contiene la transcripción original, los scripts ni los archivos de revisión. La fuente recibida permanece en fuentes dentro de la entrega local.

Las pestañas funcionan con ratón y teclado; flechas, Inicio y Fin recorren los temas. A− y A+ amplían el contenido hasta 200 %. Imprimir muestra todos los temas y respuestas. Sin JavaScript se muestran consecutivamente.

El documento editorial DOCX se elaboró antes del HTML y ambos comparten la base de contenido. Los enlaces temporales proceden de la transcripción, sin cotejo audiovisual. Las fuentes complementarias se consultaron el 8 de octubre de 2026; no se han leído íntegramente todos los libros citados.

## Imagen y redes

assets/imagen-redes.png es la versión con tipografía para compartir. assets/ilustracion-original.png conserva la generación sin texto. Imagen generada con la herramienta integrada ImageGen; metáfora visual, no fotografía documental. El prompt se conserva en PROMPT_IMAGEN.txt fuera del ZIP.

Texto sugerido para redes: Una lectura de Lorenzo Ramírez en Aladetres 183: poder, guerra, tecnología y libertad. Ideas atribuidas, pasajes enlazados y fuentes para seguir investigando. Añadir la URL publicada al compartir.

Cuando se conozca la URL pública, convertir og:image en una URL absoluta de assets/imagen-redes.png y añadir og:url y canonical con la dirección real. No se inventa una URL de publicación en esta entrega. El paquete no incluye el vídeo ni una reproducción integral de libros o transcripciones; enlaza a sus fuentes.
