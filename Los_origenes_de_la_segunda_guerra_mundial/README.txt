ATLAS HISTÓRICO INTERACTIVO

1. Abrir index.html en el navegador.
2. Para GitHub Pages, publicar el contenido de esta carpeta en la raíz del repositorio o en su carpeta de publicación.
3. Las imágenes de Wikimedia Commons se cargan desde sus servidores: se requiere conexión a Internet.
4. Metadatos OG incluyen assets/portada.svg; para plataformas que no reconocen SVG, conviene convertirla a PNG/JPG y ajustar og:image a una URL absoluta pública.
5. Las infografías, cronología, temas y contenido son locales.
6. Créditos y licencias enlazados bajo cada fotografía.
