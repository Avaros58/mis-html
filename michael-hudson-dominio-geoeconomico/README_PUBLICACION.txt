PUBLICACIÓN EN GITHUB PAGES
============================

Archivos:
- index.html
- social-card.jpg (1200 x 630 px)

1. Sube ambos archivos a la misma carpeta del repositorio.
2. Abre index.html y sustituye las dos apariciones de:
   https://TU_USUARIO.github.io/TU_RUTA/social-card.jpg
   por la URL pública absoluta de social-card.jpg.
3. Confirma que GitHub Pages está activado y abre la URL pública.
4. Los botones de compartir usarán automáticamente la URL de la página abierta.
