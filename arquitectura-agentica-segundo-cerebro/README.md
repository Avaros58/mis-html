# Arquitectura agéntica del Segundo Cerebro

## Contenido

- `index.html`: documento interactivo, responsive y autónomo.
- No utiliza imágenes, fuentes ni bibliotecas externas.
- Funciona en local y en GitHub Pages.

## Uso local

Abra `index.html` con cualquier navegador moderno.

## Publicación en GitHub Pages

1. Cree una carpeta dentro de su repositorio.
2. Copie `index.html` en esa carpeta.
3. Confirme los cambios y haga `Push origin`.
4. La dirección tendrá la forma `https://USUARIO.github.io/REPOSITORIO/CARPETA/`.

## Funciones

- Navegación por pestañas.
- Mapa interactivo de componentes.
- Secciones desplegables.
- Generador y biblioteca de prompts.
- Copia al portapapeles.
- Descarga de la biblioteca en TXT.
- Impresión o guardado como PDF.
