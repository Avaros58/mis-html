# Imperiofobia y leyenda negra · Lectura expositiva

Las tres entregas reunidas en 21 capítulos, a partir del libro de María Elvira Roca Barea. Proyecto Geopolítica–Economía.

## Archivos

- index.html: documento completo con portada ilustrada incorporada. Incluye los estilos, el índice general y los controles de lectura.
- .nojekyll: permite publicar directamente este sitio estático.
- README.md: estas instrucciones.

No requiere instalaciones, compilación ni servicios externos. Para revisarlo antes de publicar, abre index.html en un navegador.

## Publicar en GitHub Pages

1. Descomprime el ZIP en tu ordenador.
2. Crea un repositorio público en GitHub, o utiliza el repositorio elegido para este trabajo.
3. Sube los tres archivos a la raíz del repositorio mediante Add file → Upload files. Sube el contenido de esta carpeta, de modo que index.html quede directamente en la raíz; no subas el ZIP. Si .nojekyll está oculto, activa la visualización de archivos ocultos.
4. Confirma la subida con Commit changes.
5. En Settings → Pages, dentro de Build and deployment, selecciona Deploy from a branch.
6. Elige la rama main (o la rama donde hayas subido los archivos), la carpeta /(root) y pulsa Save.
7. Cuando termine la publicación, la sección Pages mostrará el enlace del sitio.

Documentación oficial: [Configurar la publicación en GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
